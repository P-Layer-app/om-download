## 1. What OmLayer Is

OmLayer is a quiet broadcast monitoring utility for everyday operations.

It helps you quickly see:

- stream offline
- silence on output
- stream restored
- metadata issues

## 2. Installation and Launch

OmLayer is used as an installed desktop app.

Typical setup:

1. Open the installer package you received.
2. Install OmLayer to `Applications`.
3. Launch OmLayer from `Applications`.

On first launch, OmLayer starts as a full 14-day trial.

If the trial is still active, monitoring starts automatically.
If the trial has expired, OmLayer opens normally but monitoring stays inactive until activation is applied.

## 3. First-Time Setup

1. Open OmLayer settings from the menu bar.
2. Paste your stream URL.
3. Click `Save`.
4. Turn `Notifications` ON if needed.
